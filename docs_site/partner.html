Partner API

Verify members and track enrollments

Use this API to check 4Ps members and record their enrollments. Sign in once, then send your token with every call.

Open the API reference Try sign-in

  1. Sign in

    Send your username and password to POST /token as a form. The reply holds your access token.

    curl -X POST https://your-host/token \
  -d "username=YOUR_USERNAME" \
  -d "password=YOUR_PASSWORD"
    {
  "access_token": "eyJhbGciOiJIUzI1NiJ9.example-payload.example-signature",
  "token_type": "bearer",
  "expires_in": 1800
}

  2. Copy the token

    Copy the value of access_token. expires_in is how many seconds it stays valid.

  3. Send it with each call

    In your code, add the header Authorization: Bearer YOUR_TOKEN.

    In this reference, open an operation and paste the token into the Token box under Auth in the Try It panel.

  4. Make your first call

    Verify a member. The values below are made up; replace them with your own.

    curl -X POST https://your-host/v1/api/tuloy/members/verify \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"first_name": "Juan", "last_name": "Dela Cruz", "date_of_birth": "1990-01-31"}'

Good to know

  • Access follows your grantsYou need an active grant for each operation's scope. You receive 403 if that grant is missing, expired or revoked.
  • Tokens expireWhen a call returns 401, sign in again to get a new token.
  • Operation contracts await approvalYou receive 501 while contracts await approval. Nothing is processed or stored. You can safely retry later. Do not build production flows on them yet.
  • Errors share one shapeEach holds detail, error_code and request_id. Quote the request ID when you ask for help.
